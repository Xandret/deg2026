# ДЭГ-2026 по открытым данным: итоги проверки

*Справка для Общественной палаты Российской Федерации. Подготовлено по данным журнала блокчейна федерального ДЭГ
(копии для наблюдателей), портала наблюдения stat.vybory.gov.ru и протоколов izbirkom.ru. Автор — Xandret.
Версия от 25.09.2026, до публичного размещения.*

## Главное

1. **Итоги ДЭГ подтверждены независимо.** Журнал всех 5 103 электронных голосований (32 региона, 18–20 сентября)
   разобран собственной программой и проверен четырьмя независимыми способами. Криптографическая проверка открытым
   верификатором подтвердила итог **каждого** из 5 103 голосований (и всех голосований 2024 и 2025 годов).
2. **Совпадение с официальными данными полное там, где его можно проверить:** явка ДЭГ 90,88 % (официально 90,87 %);
   итоги 3 001 голосования — с порталом наблюдения до единицы; все 66 проверенных электронных протоколов — с журналом.
3. **Найдено 11 особенностей** (карточки A-01…A-11). На итоги выборов ни одна не влияет, но несколько показывают, где
   наблюдателю не хватает информации. Ниже — предложения, как это исправить.

## Предложения по прозрачности ДЭГ

1. **Показывать на портале все голосования** — в том числе части выборов в Госдуму по ТИК, с указанием, к каким
   выборам и округу они относятся (A-06). Сейчас наблюдатель видит меньше половины бюллетеней без самостоятельной
   обработки журнала.
2. **Публиковать итоги всех выборов во всех регионах** (A-11).
3. **Указывать причину недействительности электронного бюллетеня** (повреждён шифротекст, не прошло доказательство)
   и отдельно — число голосов, отклонённых после закрытия (A-10). Сейчас портал показывает только число недействительных,
   а в ДЭГ оно означает технический отказ, а не испорченный избирателем бюллетень.
4. **Единое и объявленное время окончания приёма** для всех выборов (A-02); при исключениях — объявлять заранее.
5. **Официально фиксировать инциденты:** досрочное закрытие (A-01), сбои приёма (A-03) — с временем и причиной.
6. **Стабильная выгрузка журнала для наблюдателей в реальном времени** с контролем полноты (урок A-07).
7. **Машиночитаемые протоколы** (CSV/JSON) для наблюдателей без ручного сохранения страниц — чтобы сравнение
   ДЭГ и участков было полным, а не выборочным.
8. **Порядок записей в блоке:** записывать итог после данных, нужных для его проверки, или описать порядок в
   документации для наблюдателей (сейчас каждое пятое голосование с первого раза «не проверяется»).

## Ограничения

- Проверена электронная часть. Сравнение с участками — для 36 из 81 округа Госдумы (остальные протоколы собираются).
- Данные не показывают, кто как голосовал (так задумано), и не объясняют причин поведения (раннее голосование,
  переход на участок): закономерности — повод для вопросов, а не вывод о нарушениях.
- Московский ДЭГ работает на отдельной платформе; открытых данных для количественного сравнения нет.
