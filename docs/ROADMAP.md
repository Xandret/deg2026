## Технический долг

| Что | Почему важно | Как |
|---|---|---|
| Шаблон сайта — один файл ~150 КБ | трудно править | разделить на части (стили, разделы, скрипты) и склеивать при сборке |
| Разовые скрипты перепроверки (`recheck_all.cmd`, `recheck_2.cmd`) с id голосований внутри | не переносятся на другие выборы | генерировать список из `crypto_verify/statuses.csv` |
| Ручной сбор протоколов | узкое место сравнения с участками | ждать открытых данных ЦИК; пока — пакетный HAR по списку |
| Нет CI | ошибки видны только при ручном прогоне | GitHub Actions: тесты на маленьком образце данных |
| Размер открытых данных растёт (17 МБ) | долгая загрузка на медленном интернете | сжатие на хостинге, крупные таблицы — только в архиве |
