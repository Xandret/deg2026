# A-05. Исключения из списков ДЭГ (переход на бумажное голосование) — новое в 2026 году

- **Тип:** электоральная (новый механизм)
- **Вердикт:** подтверждено как явление; интерпретация причин — частично не проверяема
- **Время:** 17–20.09.2026

## 1. Наблюдение
В 2026 году впервые можно было, записавшись на ДЭГ, проголосовать на участке бумажным бюллетенем; по
README открытого набора Слотина, из списка ДЭГ также исключают проголосовавших досрочно и умерших.
В цепочке это транзакции `removeFromVotersList`.

## 2. Данные
- Исключено **38 461 человек** (разные хеши) = 0,95 % записавшихся (4 055 819); транзакций — 122 442 (по контрактам).
- По местным суткам (события-контракты): 17.09 — 4 (до начала голосования), 18.09 — 44 022, 19.09 — 30 550, 20.09 — 47 866.
- Доля исключённых по регионам (топ): Коми 2,89 %, Смоленская 2,73 %, Марий Эл 1,98 %, Новосибирская 1,93 %,
  Калужская 1,70 %, Пермский край 1,61 %, Магаданская 1,52 %, Карелия 1,49 %.
- Официальный знаменатель явки ДЭГ — список за вычетом исключённых: 3 650 803 / 4 017 358 = 90,876 %
  (Минцифры: 90,87 %). От первоначального списка — 90,01 %.
- Локальный всплеск: Ровеньская ТИК — 19 % записавшихся исключены 19–20.09 после остановки ДЭГ (A-01);
  облизбирком: ≈400 человек в Белгородской обл. перешли на бумагу после сбоя.

## 3. Альтернативные объяснения
- Смерть/досрочное голосование — малая доля; различить причины по цепочке нельзя (тип события один).
- Технические сбои ДЭГ (как в Ровеньках) — локально объясняют всплески.
- Предпочтение бумаги / недоверие к ДЭГ — правдоподобно для фоновых ~1 %, но не проверяемо по данным.

## 4. Вердикт и границы вывода
Механизм работает и виден в открытых данных; он же меняет знаменатель официальной явки. Регионы с
повышенной долей исключений — кандидаты для сравнения с бумажной явкой (этап «ДЭГ vs бумага»).
