# A-06. Структура голосования по ТИК не видна наблюдателю в агрегированном виде

- **Тип:** институциональная (пределы наблюдения)
- **Вердикт:** подтверждено
## 1. Наблюдение / 2. Данные
- В цепочке 5 103 контракта; при обходе API портала наблюдения (регион → выборы → округ → голосования) видны
  3 177. Невидимые 1 926 контрактов содержат **6 480 523 бюллетеня — 53 %** всех бюллетеней ДЭГ.
- Госдума разбита на контракты по ТИК (Карелия: 19 + 19), портал показывает на округ один contractId (одну ТИК),
  при этом счётчики — окружные, а `issued` превышает число избирателей (суммирует все голосования).
- Интерфейс портала публиковал идентификаторы транзакций (с УИК, выдавшим бюллетень) — т.е. разбивка
  доступна только на уровне отдельных транзакций (со слов А., наблюдателя ОП).
- На izbirkom ДЭГ отдельно не показан: в протоколах ТИК его нет, протокола ТИК ДЭГ на сайте нет; ДЭГ
  виден только как «протокол ОИК − Σ протоколов ТИК».
## 3–4. Вердикт
Чтобы проверить ДЭГ-часть итога, наблюдателю нужно выгрузить и разобрать весь блокчейн (~50 ГБ) и вручную
собрать протоколы ОИК и всех ТИК с сайта с обфускацией чисел. Мы это сделали выборочно — итог совпадает
(5 ОИК, 91 строка), но сама процедура показывает высокий порог входа для общественного контроля.
