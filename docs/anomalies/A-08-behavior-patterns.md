# A-08. Поведенческие паттерны: первый час, УИК со 100 % явкой ДЭГ, ночное голосование

- **Тип:** электоральная (индикаторы организованного голосования)
- **Вердикт:** подтверждено как статистический паттерн; причинная интерпретация — не проверяема по открытым данным
- **Единица:** человек (первый полученный бюллетень), местное время региона

## 2. Данные
- **Первый час (18.09, 08:00–09:00 местного):** по стране 22,0 % всех проголосовавших. Выше всего: Курганская 32,5 %,
  Марий Эл 30,1 %, Смоленская 28,7 %, **Свердловская 28,3 %**, Алтайский край 27,3 %; ниже всего: Мурманская 14,9 %,
  НАО 15,2 %, Московская 16,4 %. В пятницу (18.09) — 78,3 % всех проголосовавших.
- **УИК с явкой ДЭГ 100 %** (список ≥50, все записавшиеся, кроме исключённых, получили бюллетень): 83 из 22 914.
  Концентрация: **Чувашия — 37 УИК (4,8 % её УИК)**, Алтайский край 7, Московская 5, Новгородская, Смоленская,
  Удмуртия, Ростовская — по 4. УИК с явкой выше 100 % — 0.
- **УИК, где ≥50 % проголосовавших — в первый час** (≥50 человек): 24; из них Курганская 8, Белгородская 4, Свердловская 4.
- **Ночное голосование (до 08:00 и после 20:00 местного):** 6,4 % по стране (Магадан 8,9 %, Пермский край 8,3 %,
  Нижегородская 8,3 %). ДЭГ был круглосуточным законно — это не нарушение, а поведенческая метрика
  (поправка к формулировке «вне законных часов» на графиках 20.09).

## 3. Альтернативные объяснения
- Организованное голосование по месту работы/учёбы («в начале рабочего дня») — даёт пик первого часа и 100 % УИК.
- Структура записавшихся: на ДЭГ записываются наиболее мотивированные → высокая явка — ожидаема;
  маленькие специальные УИК (общежития, воинские части, закрытые учреждения) — 100 % без принуждения.
- Часовой пояс/привычки — объясняют разницу регионов в первом часе частично.

## 4. Вердикт и границы вывода
Паттерны устойчивы и концентрированы в отдельных регионах (Чувашия, Курганская, Свердловская). По открытым
данным нельзя отличить мобилизацию от добровольного раннего голосования. Нужны: сравнение с 2024/2025 и с
бумажной явкой тех же УИК (этапы «динамика» и «ДЭГ vs бумага»), а также профиль УИК (тип учреждения).
