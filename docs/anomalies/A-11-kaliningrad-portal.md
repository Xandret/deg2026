# A-11. Калининградская область: итоги ДЭГ местных выборов не показаны на портале наблюдения

- **Тип:** институциональная (прозрачность)
- **Вердикт:** подтверждено (по данным портала на 24.09, 12:16 МСК); причина не проверяема
- **Регион / контракты:** Калининградская обл., 176 голосований на 12 выборах (Законодательное собрание и 11 муниципальных), 173 072 бюллетеня

## 1. Наблюдение
Портал stat.vybory.gov.ru показывает итог каждого голосования, кроме выборов в Госдуму, для которых части по ТИК
не видны (A-06). У 3 001 голосования итог на портале есть и до единицы совпадает с журналом. У 176 калининградских —
статус `RESULT_COMPLETED`, но `hasResults: false`: итога нет, строк бюллетеня (кандидатов, партий) тоже нет.

## 2. Данные
| | Голосований | Итог на портале | Итог в журнале |
|---|---:|---|---|
| Калининградская обл., Госдума (видимые на портале) | 4 | есть | есть, совпадает |
| Калининградская обл., Законодательное собрание | 40 | нет | есть |
| Калининградская обл., 11 муниципальных выборов | 136 | нет | есть |
| Остальные регионы, все выборы кроме Госдумы | 2 997 | есть | есть, совпадает |

- Итоги всех 176 голосований есть в журнале (транзакции `results`) и прошли криптопроверку (docs/tech/08-crypto.md).
- Тип бюллетеня (партсписок `UNION` / кандидаты `SINGLE`) портал показывает и здесь — по нему голосования разнесены
  по типам. Имена кандидатов и партий неизвестны, поэтому в «Все выборы» они обозначены номером строки бюллетеня.
- Сбор портала: data/external/portal/raw, `collectionTime` 24.09.2026 11:11 (местн.), `fetched_utc` 09:11–09:16.

## 3. Альтернативные объяснения
- Региональный организатор не включил публикацию итогов на портале (настройка). Проверить можно только у ИКМО/ЦИК.
- Итоги опубликуют позже. На момент сбора — через 4 дня после выборов — их не было.
- Связь с предварительными итогами Госдумы (партсписки ДЭГ без Калининграда в 21:32 МСК 20.09, см. хронологию) —
  совпадение региона, прямой связи по данным нет: в Госдуму калининградские итоги на портале есть.

## 4. Вердикт
Подтверждено. На итоги не влияет, но наблюдатель без собственной обработки журнала не видит результатов ДЭГ
на 12 выборах в регионе, а сопоставить номер строки с кандидатом можно только по официальному протоколу.
