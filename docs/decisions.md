# Журнал решений

Формат: дата — решение — почему — какие альтернативы отклонены.

## 2026-09-24 — исходная рамка (итог интервью)

1. **Продукты.** Курсовая + полный технический отчёт (база) + публичный продукт (свой сайт + лонгрид).
   Сначала закрытая страница, затем GitHub Pages под ником; настоящее имя — после согласования с ОП.
2. **Тема курсовой.** «Прозрачность федерального ДЭГ как институт общественного контроля: эмпирический
   анализ выборов 2026 года». Научный руководитель — П.С. Каневский (смена темы с лоббизма).
   Идём к нему с 2–3 готовыми карточками аномалий.
3. **Исследовательский вопрос.** Какие аномалии позволяют выявить открытые данные ДЭГ и где проходят
   пределы такого наблюдения. Рамка — наблюдаемость/проверяемость; технический аудит и электоральная
   статистика — эмпирические главы. Язык: «аномалия», «артефакт»; выводы ограничены тем, что данные
   позволяют утверждать.
4. **План текста.** Гл.1 теория (CM/Rec(2017)5; Эстония, Швейцария, Норвегия; московский ДЭГ —
   институционально, т.к. дампа Москвы в 2026 нет). Гл.2 ДЭГ-2026 как объект наблюдения (архитектура,
   что открыто, как собирали данные — включённое наблюдение, ограничения). Гл.3 каталог аномалий.
5. **Карточка аномалии.** наблюдение → данные → альтернативные объяснения → вердикт
   (подтверждено / объяснено технически / артефакт наблюдения / не проверяемо). 6–8 карточек в
   основной текст, полный каталог — в приложение. Шаблон: `docs/anomalies/_template.md`.
6. **Независимость данных.** Всё считаем сами: свой парсер сырых блоков, свой сбор с izbirkom.
   Таблицы С. Слотина (sslotin/elections) — только для сверки; совпадение подаётся как независимое
   воспроизведение. **Ссылки на команду и литературу обязательны** (отклонено: «без ссылок» —
   академический риск и неверно по существу: дампы собирались скриптом команды).
7. **Люди и секреты.** Участники — по ролям; по именам только публичные лица в публичной роли
   (Д. Кузнецов — конструктор ПТК ДЭГ; О. Артамонов — пред. ТИК ДЭГ; В. Толстогузов; С. Слотин как
   автор публичного репозитория). Секреты из чата не используются нигде; ChatExport только локально.
8. **Сравнение ДЭГ vs бумага** — на уровне одномандатных округов Госдумы / ТИК (итоги ДЭГ есть только
   по контракту, не по УИК).
9. **Свердловская «заморозка»** — описывается как реконструкция (наиболее вероятно: сбой
   `dump-chunked.py` «different history» → 0 новых блоков при повторном запуске на той же флешке;
   объяснение про КЭГ/ТЭГ пришло искажённым через посредника; Д. Кузнецов уточнил: ЭСИ ДИТ Москвы).
10. **Вычисления.** Тяжёлое — нативно в Windows (i9-14900K, 32 ГБ), 12 процессов. Криптопроверка —
    только режим «итоги». Блоки расшифровки — из публичного edg2026.tar со сверкой хешей с нашим day3.
11. **Новости.** Сборщик веб-превью публичных Telegram-каналов (`t.me/s/…`), без авторизации;
    ручной отбор 40–60 событий, баланс: официальные / независимые / СМИ.
12. **Порядок работ.** 1 инфраструктура → 2 парсер+сверка → 3 izbirkom (фон) → 4 метрики и карточки →
    5 криптопроверка → 6 новости (фон) → 7 сайт → 8 текст (.docx по требованиям соцфака).
13. **Режим работы.** Тандем: код пишет Claude, по каждому модулю — техдокументация в `docs/tech/`,
    по которой Алекс разбирается после.

## 2026-09-24 — итоги этапа 2

    через управление компьютером нельзя). Для этого добавлены `--time-budget` (parse_blocks),

16. **edg2026.tar для итогов не нужен:** day3 содержит расшифровку и итоги всех 5 103 контрактов.
    Решение №10 уточнено: публичный архив — только для сверки хешей (необязательно).

## 2026-09-24 — динамика 2024→2026

18. **24.09: 2024/2025 переведены на собственный парсинг.** Сверка со Слотиным: 2024 — 1 234 722 бюллетеня,
    1 226 056 голосов, списки и итоги 2 103 голосований; 2025 — 2 901 964 / 2 881 290 / 3 046 — 0 расхождений.
    (F-проверка 2024: 8 контрактов Слотина без бюллетеней — это голосования без единого бюллетеня, у нас они
    тоже есть как созданные контракты; итоги всех 2 103 совпадают.) `dynamics` по умолчанию берёт наши базы.
19. **Криптопроверка — открытым верификатором С. Слотина** (feddeg/verification/opensource, без модификаций,
    ссылка обязательна), режим `--results-only`; результаты прогона — наши. Отклонено: писать свою реализацию
    ГОСТ-кривых/ElGamal/ZKP (недели работы, выше риск ошибки; для курсовой важен результат проверки).
    Проверяются 2026 (7 цепочек) и сырые дампы 2024/2025.

## 2026-09-24 — сайт (этап 7)
20. **Сайт — одна самодостаточная страница** (без фреймворков и внешних библиотек): шаблон
    `site/page.tmpl.html` + данные, встроенные при сборке (`site/build.py`). Сначала закрытая страница
    (Artifact на claude.ai), потом тот же файл — на GitHub Pages под ником. Геометрия — Natural Earth
    (общественное достояние), проекция Альберса; в NE перепутаны коды RU-MOW/RU-MOS — сверено по площади.
21. **На сайт — только агрегаты** (регион, УИК по публичному номеру комиссии). user_id и хеши списков не
    выходят за пределы расчётов. Имена — только кандидатов (в роли кандидатов) и должностных лиц/авторов
    источников в публичной роли; участники рабочего чата не называются.
22. **Карта — квинтили по 32 регионам**, одна синяя шкала для всех показателей (цвет не означает «хорошо/
    плохо»); таблица всех регионов дублирует карту (доступность).
23. **Сайт v2 — «карта на весь экран»** (тон и компоновка DeepStateMAP по просьбе Алекса; без элементов
    их бренда). Разделы переключаются по `#адресу`; мобильная версия — кнопки показателей над картой и
    выдвижная панель региона снизу; для неспециалиста — приветствие и раздел «Что это».
24. **Итоги ДЭГ по всем регионам — из журнала, бумага — из протоколов по мере сбора.** Контракты ГД
    разбиты на пары по ТИК (docs/tech/06-deg-results.md); 42 из 81 округа собраны реконструкцией по сходству
    результатов — на сайте помечены «Реконструкция» до сверки. Алекс собирает HAR: сводная таблица по
    федеральному округу (партии, все субъекты) + сводные таблицы ОИК по всем округам.
25. **Протоколы — из открытого снимка izbirkom (github.com/Arhydemon/elections_20_09_26), после проверки.**
    Отступление от «всё сами» (решение №4): снимок сверен с нашими HAR (384 строки, 0 расхождений) и с
    блокчейном (66 протоколов ДЭГ, все совпали) — используем со ссылкой. Недостающие 48 ОИК (92 страницы) — HAR вручную
    (docs/izbirkom_todo.md). Их загрузчик не запускаем; обход защиты сайта по-прежнему исключён.
26. **Криптопроверка: неподтверждённые голосования перепроверяем, а не списываем.** Код верификатора не
    меняем; меняем только вход (дамп с нужными контрактами, `results` в конце блока) и явно помеченные режимы
    обёртки (`--allow-bad-ballots`, `--full`). Два несовпадения итога не публикуем как нарушение до полной
    проверки (docs/tech/08-crypto.md).
27. **Хронология (этап 6): публичные Telegram-каналы, без «нежелательных организаций».** Источники: ЦИК России
    (@cikrossii), Общественная палата, «Госуслуги», ТАСС, РБК, «Коммерсантъ», «Ведомости», В. Толстогузов;
    «Голос» (иноагент) — с пометкой, но его канал в период выборов не публиковал. Минцифры в Telegram молчит
    с марта 2026 — его заявления берём через СМИ. Сбор — веб-версия t.me/s (1 запрос/с), отбор событий вручную
    (data/news/timeline.json); у каждого события — сверка с данными журнала.
28. **Карта — 89 субъектов по Конституции РФ** (включая ДНР, ЛНР, Запорожскую и Херсонскую области; Крым и
    Севастополь были и раньше). Сайт предназначен в том числе для официальных адресатов в РФ; подпись на карте и в
    методике — «границы — по Конституции РФ». Федеральная платформа ДЭГ в этих четырёх субъектах не применялась
    (показаны серым). Контуры — административные границы Natural Earth.
29. **Хронология: реестр источников `data/news/sources.json`** — тип (официальный канал / крупное федеральное СМИ /
    региональное СМИ / наблюдатель) и статус иностранного агента. Для материалов иноагентов сайт выводит
    маркировку по форме, утверждённой Правительством РФ (с 01.12.2022). Статусы сверяются с реестром Минюста
    перед публикацией; «нежелательные» организации не используются. 49 событий, 15 источников.
30. **Публичный сайт: статическая папка `site/public`, .ru + зеркало GitHub Pages, запуск после ОП.** Сборка
    по умолчанию закрыта от поисковиков (`noindex`, `Disallow: /`); открывает её только флаг `--launch`. Зеркало
    выкладывается вручную запуском workflow. Открытые данные — CSV (UTF-8 с BOM) + книга Excel + архив, CC BY 4.0;
    только агрегаты. На сайте нет cookies и счётчиков. Хостинг, домен и оплату оформляет Алекс
    (docs/tech/10-public-site.md).
31. **Уборка 24.09: промежуточные файлы удалены, исходники не тронуты.** Удалены склеенные цепочки
    `data/derived/chain_dumps/*.jsonl.gz` (53,5 ГБ; пересборка — `run.cmd make_chain_dumps`, сверка по `_manifest.json`),
    вырезки `crypto_recheck/*.jsonl.gz` (5 ГБ; итоги в `*.json`), установщик и исходники GnuPG. Логи верификатора сжаты
    в `logs/*.log.gz` (3,8 ГБ → 29 МБ); `crypto_recheck parse` читает их напрямую, результат побайтно совпал.
    Модуль `deg_vs_paper` (5 округов) заменён `izbirkom_snapshot`. `edg_day1/2.zip`, дампы 2024/2025 и parquet
    оставлены до отдельного решения.
