Протоколы ОИК: запись HAR (92 страниц)

  1. Открыть ссылку, дождаться таблицы (проверку сайта, если попросит, пройти самому).
  2. F12 → Network → F5 → дождаться таблицы.
  3. ПКМ по запросам → «Save all as HAR with content» → deg2026\data\external\izbirkom\, имя — как в списке.
  4. Поставить галочку. В конце: run.cmd reconcile_izbirkom, run.cmd izbirkom_snapshot, scripts\build_site.cmd.

Открывайте в обычном темпе, не подряд пачкой: сайт защищается от автоматического сбора.
