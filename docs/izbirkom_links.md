# Прямые ссылки на протоколы ОИК для записи HAR

Сформировано из снимка izbirkom (id комиссий) и списка `data/derived/izbirkom_snapshot/todo_oik_protocols.csv`.
Удобнее открывать файл `docs/izbirkom_links.html` — там те же ссылки кнопками и отметки «сделано».
Всего страниц: **92**.

**Как записать одну страницу (≈1 мин):**
1. Открыть ссылку в обычном браузере, дождаться, пока появится таблица (если сайт попросит проверку — пройти её самому).
2. F12 → вкладка Network (Сеть) → обновить страницу (F5) → дождаться таблицы.
3. Правой кнопкой по списку запросов → «Save all as HAR with content» (Сохранить всё как HAR).
4. Сохранить в `deg2026\data\external\izbirkom\` с именем из списка ниже.
5. После всех — `run.cmd reconcile_izbirkom`, `run.cmd izbirkom_snapshot`, `scripts\build_site.cmd`.

Не нужно открывать ссылки быстро подряд: обычный темп человека (сайт защищается от автоматического сбора).
