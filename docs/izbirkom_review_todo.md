# Протоколы для рецензии Д.: A-10 (недействительные) и Калининград (A-11, п. 14 плана)

Составлено 01.10.2026. Запись HAR — как в `docs/izbirkom_links.md` (F12 → Network → «Preserve log» → пройти страницы →
«Save all as HAR with content»), обычным темпом, проверку сайта проходить самому. Файлы — в `data\external\izbirkom\`
(в git не попадают). Можно записывать несколько страниц в один HAR: включить «Preserve log» и пройти их подряд.

**Главное на каждой странице ОИК:** если в списке нижестоящих комиссий есть строка «Дистанционное электронное
голосование» (в снимке — № 9000), открыть и её протокол, в той же записи. Это официальный протокол ДЭГ по округу,
строка 9 в нём — «Число недействительных избирательных бюллетеней» только по ДЭГ. Если такой строки нет — пройти
все ТИК округа (тогда ДЭГ = ОИК − Σ ТИК).
