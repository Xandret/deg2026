## Находка 1. Портал показывает 3 177 из 5 103 контрактов
В цепочке 5 103 контракта, при обходе API портала «регион → выборы → округ → голосования» видны 3 177.
**Невидимые 1 926 контрактов содержат 6 480 523 бюллетеня — 53 % всех бюллетеней ДЭГ-2026.**

Механизм (проверено на Республике Карелия, Госдума):
- В цепочке выборы в Госдуму по Карелии разбиты на контракты по ТИК: 19 контрактов партсписка
  (10 позиций) и 19 — одномандатного округа (11 кандидатов), попарно с одинаковыми УИК и числом бюллетеней.
- Портал для округа «Карельский» отдаёт ровно два contractId (SINGLE и UNION) — **один ТИК-контракт из 19**.
  Итоги портала по этим contractId (513 голосов за ЕР и т.д.) — итоги **одного ТИК**, не округа
  (сумма по 19 контрактам партсписка: 31 932 голоса, из них ЕР 11 727).
- Счётчики портала при этом «окружные»: `all` = 35 920 (все записавшиеся на ДЭГ в округе),
  `issued` = 129 483 / 135 038 — больше, чем избирателей, т.к. считают выдачи по всем голосованиям.

Как это выглядело для наблюдателя (со слов Алекса, работавшего с порталом 18–20.09): интерфейс
публиковал идентификаторы транзакций; в транзакции — в основном техническая информация и то, какой
УИК выдал электронный бюллетень. Т.е. структура «по ТИК» была доступна **только на уровне отдельных
транзакций**, а агрегированные итоги и счётчики показывались на уровне округа с привязкой к одному
contractId. Формулировка для текста: «структура голосования по ТИК технически открыта, но не
агрегирована: чтобы увидеть её, наблюдателю нужно выгрузить и разобрать весь блокчейн».

Следствия:
1. Для анализа результатов по округам нужно самим сопоставить невидимые контракты с выборами.
   План: (а) связка «соседей» — у одного избирателя выдача атомарна, поэтому контракты одного ТИК
   имеют совпадающие (УИК, секунда) выдачи (проверено на Ровеньской ТИК: 613/613);
   (б) число позиций бюллетеня (dimension) + число кандидатов в итогах портала;
   (в) справочник УИК → ТИК → округ с izbirkom (этап 3).
2. Карточка аномалии «А-00: непрозрачная структура контрактов» — кандидат в главу 2.
3. Контракты Ровеньской ТИК (одномандатный Старооскольский и партсписок) — как раз из невидимых.

## Находка 2. Счётчик `issued` портала не равен числу людей
Сумма `issued` по федеральным SINGLE-записям — 9 837 439 при `all` 4 017 712. Использовать
счётчики портала для явки нельзя (так же предупреждал README feddeg-data).
