# 05. Сайт: карта, профили регионов, каталог аномалий

## Что это
Одна HTML-страница без внешних зависимостей: карта регионов ДЭГ с выбором показателя, профиль региона
(почасовая выдача, распределение явки по УИК, динамика 2024–2026, участки с максимальной явкой), таблица
всех регионов, каталог аномалий A-01…A-09, сравнение «ДЭГ против бумаги», слои проверки, методика.
Закрытая версия опубликована как Artifact на claude.ai (доступ только у владельца).

## Как собрать
```
run.cmd site_data        # агрегаты из deg2026.duckdb → data/derived/site/site_data.json (секунды)
run.cmd deg_results; run.cmd izbirkom_snapshot   # итоги ДЭГ и бумага
scripts\build_site.cmd   # открытые данные + site\public\ и site\dist\ (docs/tech/10-public-site.md)
```
`site/dist/` в .gitignore — это продукт сборки. `site/geo.json` в репозитории (≈93 КБ).
Пересобрать геометрию: скачать `ne_10m_admin_1_states_provinces.geojson` (naturalearthdata.com) в
`data/external/`, `pip install shapely pyproj`, `cd site && python geo.py`.

## Показатели (как считаются)
| Показатель | Формула | Откуда |
|---|---|---|
| Явка ДЭГ | бюллетени / (нач. список + добавленные − исключённые), по представительному контракту УИК | `site_data.py`, тот же метод, что `dynamics.py` |
| Первый час | доля бюллетеней 18.09 08:00–09:00 местного | `regions_by_year.csv` (2026) |
| Без голоса | 1 − голоса / бюллетени, все контракты региона | `site_data.py` |
| УИК со 100 % | УИК со списком ≥ 50, где бюллетеней ≥ списка | `site_data.py` |
| Исключены | исключённые / начальный список (представительный контракт) | `site_data.py` |
| Видно на портале | бюллетени в контрактах, найденных обходом портала / все бюллетени региона | `portal/contracts.parquet` |
| Почасовая кривая | выдача по часам МСК → сдвиг в местное (сдвиг = 8 − час первого бюллетеня) | `site_data.py` |

Контроль сумм при сборке: список 4 017 333, бюллетеней 12 202 035, на портале 5 721 512 (= 12 202 035 − 6 480 523).

## Устройство страницы (для чтения кода)
Версия 2 (24.09): интерфейс «карта на весь экран» в тёмной палитре по образцу DeepStateMAP
(только тон и компоновка — без их имени, логотипа и элементов бренда).
- **Разделы** — одна страница, переключение по адресу после `#`: `#map`, `#about`, `#regions`,
  `#anomalies` (и `#anomalies/A-03` — сразу к карточке), `#paper`, `#verify`. Кнопка «Назад» в браузере работает.
- **Токены** — CSS-переменные в `:root`: поверхности `--bg #000`, `--panel #282a2f`, текст `--text-2 #d4d4d5`,
  шрифт Helvetica Neue, скругления 8/12 px, анимации 150 мс. Светлая тема — `[data-theme="light"]`,
  переключатель в шапке, выбор запоминается в localStorage (всё обёрнуто в try/catch).
  Отступление от присланного образца: ссылки `#8ab4ff` вместо `#0000ee` — синий на чёрном не проходит контраст WCAG.
- **Карта** — SVG, `viewBox` двигается: мышь (перетаскивание, колесо), палец (перетаскивание, щипок),
  кнопки +/−, пресеты «Вся страна / Европа и Урал». Нажатие отличается от перетаскивания порогом 6 px
  (`drag.moved`), регион определяется через `elementFromPoint`. Кружки аномалий масштабируются обратно
  зуму, чтобы оставаться одного размера.
- **Компьютер:** слева плавающая панель (показатель, шкала, пояснение, итоги), справа — профиль региона.
  **Телефон (≤ 760 px):** показатели — кнопки над картой, шкала — полоска внизу, профиль — выдвижная панель
  снизу (свёрнута → развёрнута: нажатие или свайп по полоске).
- **Для неспециалиста:** окно-приветствие при первом входе (3 пункта; кнопка «?» открывает снова),
  раздел «Что это»: ДЭГ за 4 шага с тем, что из каждого шага видно в журнале; что значит каждый показатель,
  какое значение обычно и почему он интересен; как пользоваться; вердикты; словарь.
- Данные встраиваются в `<script type="application/json">` (geo, data, paperData) — страница работает офлайн.
- Графики — рукописный SVG (линия, гистограмма, «гантели»); подсказки по наведению и по касанию.
- Карточки аномалий — массив `CARDS` в шаблоне; при изменении `docs/anomalies/*.md` правится вручную.
