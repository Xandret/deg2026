# 07. Снимок протоколов izbirkom: проверка и использование

Модуль: `src/deg/izbirkom_snapshot.py` (`run.cmd izbirkom_snapshot`).
Источник: открытый снимок izbirkom.ru по выборам в Госдуму от 22.09.2026 —
github.com/Arhydemon/elections_20_09_26. Скачан 24.09 в `data/external/izbirkom_snapshot/`
(`SOURCE.txt`, `SHA256SUMS.txt`); в git не попадает. `candidate_cards.jsonl` (личные данные кандидатов)
не скачивали. Загрузчик из этого репозитория не запускали — используем только готовые файлы.

## Почему ему можно доверять (проверки)
| Проверка | Результат |
|---|---|
| A. Протоколы из наших собственных HAR ↔ те же протоколы в снимке | 20 протоколов, 384 строки, **0 расхождений** |
| B. Официальные протоколы ДЭГ (в снимке — отдельный протокол `isDeg` под ОИК) ↔ блокчейн | 66 протоколов (33 округа × 2), **все совпали** |
| B2. Те же протоколы ДЭГ, **все строки** (1–12 и кандидаты/партии) ↔ журнал (`deg_rows`, `chain_totals`) | 66 протоколов, 1 361 строка, **все совпали** (02.10) |
| Контрольные соотношения каждого протокола ОИК (10 = Σ кандидатов; 7 + 8 = 9 + 10; 1, 2 ≥ 3 + 4 + 5) | 151 протокол, нарушений 0 |

B заодно подтвердил реконструкцию округов из `deg_results`: 13 округов, собранных по сходству результатов,
совпали с официальными протоколами ДЭГ.

B2 нашёл и поправил две особенности журнала: «принято» — только голоса, записанные контрактом (поздний голос
в Дмитровском округе, A-10, в протоколе не учтён ни как принятый, ни как недействительный); «в списке» — люди, а не
«добавлено − исключено» (в Сыктывкарском одного избирателя исключили дважды).

## Покрытие
Снимок неполный (~30 % УИК, 82 из 225 ОИК по стране). Из 81 округа в регионах ДЭГ (на 02.10):
- 33 — есть протокол ОИК и протокол ДЭГ → бумага = ОИК − ДЭГ (источник «снимок izbirkom»);
- 4 протокола — наши HAR с протоколами всех ТИК (Белгородский, Старооскольский, Магаданский — одномандатные,
  Карельский — партии; «наша запись HAR»);
- 81 протокол — наши HAR только ОИК (02.10, 46 округов): бумага = ОИК − ДЭГ из журнала (D; «наша запись HAR;
  ДЭГ — журнал»). Метод проверен B2.
Итого бумага есть для 79 из 81 округа: одномандатные — 76, партсписки — 75. Не хватает 11 страниц
(`docs/izbirkom_todo.md`). Партии по региону — только если есть протоколы всех округов региона: 27 регионов.

## Покрытие снимка по уровням комиссий (проверка 24.09)
| Уровень | Всего комиссий | С протоколом в снимке |
|---|---:|---:|
| ОИК (тип 3) | 225 | 82 |
| ТИК (тип 4) | 2 940 | 966 |
| УИК (тип 5) | 91 381 | 27 866 |

Для каждого из 81 округа ДЭГ-регионов проверено: все ли ТИК округа имеют протокол, а если нет — все ли УИК этих ТИК.
Полное покрытие без протокола ОИК не нашлось ни в одном округе, поэтому 48 округов остаются в ручном списке
(docs/izbirkom_todo.md). Дерево комиссий — `children`/`parentId` в commissions.jsonl.
