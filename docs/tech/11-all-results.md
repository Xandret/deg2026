# Итоги ДЭГ по всем выборам (`all_results`)

`run.cmd all_results` → `data/derived/all_results/{contracts,options,races}.csv`, `report.json`,
`data/derived/site/elections.json` (раздел сайта «Все выборы»).

## Источники
- **Итог** — транзакция `results` каждого из 5 103 контрактов (массив голосов по строкам бюллетеня; размерность
  `[[1, мест, строк]]` из `dimension`). Итоги проверены криптографически (docs/tech/08-crypto.md).
- **Названия** выборов, округов, кандидатов и партий, тип бюллетеня (`UNION` — партсписок, `SINGLE` — кандидаты) —
  портал stat.vybory.gov.ru (docs/tech/02-portal.md). Госдума — из `deg_results` (1 926 её контрактов на портале не видны, A-06).

## Сверка
| Проверка | Результат |
|---|---|
| Итог журнала = итог портала (все строки, до единицы) | 3 177 из 3 177 голосований, где портал публикует итог (02.10; на 24.09 — 3 001 из 3 001) |
| Выдано бюллетеней (журнал) = `issued` портала | 3 015 из 3 015 не-думских голосований |
| Принято голосов = `voted` портала | 3 014 из 3 015; расхождение на 1 — отклонённая контрактом транзакция (A-10) |
| Тип `UNION`/`SINGLE` = разбор имён (партии или люди) | 3 177 из 3 177 |
| Без итогов на портале | 0 (02.10); на 24.09 — 176, все Калининградская обл. (A-11) |

## Что получилось
637 выборов: Госдума (2 088 голосований), губернатор Белгородской области (22), 20 региональных выборов
(14 заксобраний и 6 довыборов; 709 голосований), 595 муниципальных выборов (2 284 голосования: 1 065 одномандатных
округов, 688 многомандатных, 16 партсписков, 2 главы поселений). «Гонка» (`races.csv`) — округ или вся территория
(партсписок, губернатор, глава); голоса частей по ТИК сложены. Места в гонке — по голосам; при равенстве выше тот,
кто выше в бюллетене (у кандидатов это алфавит, у партий — жеребьёвка), затем — по названию, так что пересборка
даёт те же файлы. Ничья за 1-е место в CSV — `place1_votes` = `place2_votes` (в одномандатном округе это и
`margin_pp` = 0); на сайте показаны все, кто делит 1-е место.

Наблюдение для курсовой: в каждом из 13 заксобраний с опубликованным бюллетенем «Единая Россия» в ДЭГ получила меньше,
чем на выборах в Госдуму в том же регионе теми же избирателями ДЭГ: от −0,9 (Алтайский край, Пермский край) до
−5,8 п. п. (Карелия); Московская обл. −3,7.

## Ограничения
Это только электронная часть. Бумага по региональным и муниципальным выборам не собиралась (снимок izbirkom —
только Госдума). «Лидер в ДЭГ» не означает победителя выборов.
