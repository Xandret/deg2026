# Московский ДЭГ-2026: что доступно для сравнения (разведка 24.09)

Итог: **количественно сравнить московский ДЭГ с федеральным по открытым данным нельзя** — открытой выгрузки журнала
московской платформы мы не нашли. Возможно только институциональное сравнение (как устроено наблюдение).

## Что проверено
| Что | Результат |
|---|---|
| Платформа | Отдельная от федеральной (ДИТ Москвы, mos.ru); федеральная — 32 региона, Москвы в ней нет |
| Портал наблюдения | observer.mos.ru — одностраничное приложение «Статистика голосования», версия 2.5.3 |
| Настройки портала (config.js, 24.09) | `SHOW_FIND_VOTE_PAGE: true` (поиск своего голоса включён), `SHOW_BLOCK_TRANSACTIONS_PAGE: false` (страница транзакций блоков выключена) |
| Доступ к журналу | по mos.ru: технические наблюдатели могли подключаться к ноде блокчейна **в штабе наблюдения** (очно); публичного архива не нашли |
| Федеральный ДЭГ для сравнения | копии всех 7 цепочек выданы наблюдателям; портал stat.vybory.gov.ru с API; открытые таблицы Слотина |

## Что можно сравнить без данных
Наблюдаемость по одной схеме (для курсовой, рамка CM/Rec(2017)5): кто и когда получает журнал; можно ли проверить
итог самостоятельно (у федерального — да, криптопроверка 5 103 из 5 103); видны ли отклонённые/отброшенные голоса
(у федерального — только из полной проверки, A-10); публикуется ли связка «голосование ↔ выборы» (A-06, A-11).

## Что нужно, чтобы сравнить цифры
Выгрузка с московской ноды наблюдателя (если ОП или штаб её получали) или официальный архив ДИТ. Спросить в ОП.
