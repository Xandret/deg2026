# Открытые данные deg2026 — ДЭГ-2026 по данным блокчейна

Производные данные проекта deg2026 (автор — Xandret). Лицензия CC BY 4.0: можно использовать и перерабатывать с указанием источника «deg2026 / Xandret».
Источники: дампы блокчейна федерального ДЭГ (копии для наблюдателей), портал наблюдения stat.vybory.gov.ru, протоколы izbirkom.ru (в т.ч. открытый снимок github.com/Arhydemon/elections_20_09_26, проверенный нами), верификатор С. Слотина. Методика — раздел «Проверка» на сайте и docs/ в репозитории.
Персональных данных нет: только агрегаты, номера комиссий и идентификаторы голосований.

CSV — UTF-8 с BOM, разделитель запятая. В Excel удобнее открыть deg2026_tables.xlsx или «Данные → Из текста/CSV».
